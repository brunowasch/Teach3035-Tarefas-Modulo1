# 👨‍💻 Módulo 1 - Front-end: Tarefas 

Este repositório contém as tarefas desenvolvidas por mim durante o Módulo 1 do programa 3035Teach, oferecido pela empresa [3035Tech](https://www.3035tech.com/).


O foco deste módulo é o aprendizado dos fundamentos de Front-end básico, explorando conceitos de HTML, CSS e JavaScript.

![Teach_3035](https://github.com/user-attachments/assets/119aaa28-437a-4aba-8575-007b79998fba)

## 🚀 Conteúdo do Módulo

No decorrer do módulo, os seguintes tópicos foram abordados:
- Estruturação de páginas com HTML5
- Estilização e layout com CSS3
- Interatividade e lógica com JavaScript
- Boas práticas de organização de código
